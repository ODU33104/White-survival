# Whiteout Survival ad reference archive

このフォルダは **広告ゲーム部分を研究して、オリジナルのブラウザゲームとして再構成するための参照資料** です。

第三者の広告動画・画像そのものは公開リポジトリへ転載せず、元URL、確認日、尺、画面比率、ゲームループ、画面構成、実装時に再現すべき特徴を保存します。

## 実装前のルール

1. 新しいステージを作る前に、該当する広告資料を実際に確認する。
2. キャラ、資源、施設、UIの「画面内の相対サイズ」を先に決める。
3. 動画から、移動速度・採取テンポ・投入テンポ・カメラ挙動を確認する。
4. 広告素材そのものはコピーせず、ゲーム内アートはオリジナルに描き起こす。
5. 実装後はスマホ実機相当の 9:16 画面で比較する。

## 現時点での広告共通仕様

- 基本は **9:16の縦画面**
- プレイヤーは画面幅の約 8〜12% 程度で読み取れる大きさ
- ワールドは広大に見せず、1画面〜数画面分の狭い作業場
- 収集物はインベントリ数字だけではなく **キャラの背後/頭上へ大量スタック**
- 投入地点へ近づくと、所持物が高速で1個ずつ吸い込まれる
- 「資源を取る → 目に見えて運ぶ → 目に見えて消費 → 建物/火/人数が変化」が1画面で追える
- UIよりゲームオブジェクトが主役。広告ではキャラ・木・炉・魚・熊が大きい
- 画面下側をドラッグする仮想スティック系操作が中心
- カメラはプレイヤーに追従し、プレイヤーを小さく固定俯瞰しない
- 成長地点/購入地点は地面に直接置かれ、必要コストがその場に表示される
- 採取・投入・建築のたびに、数字、物理スタック、パーティクル、建物変化が即時に返る

## 次に収集するもの

- 各広告のキャラクター外見（頭身、服、道具、向き）
- 木・丸太・魚・肉・石炭・貨幣の形状
- 炉/調理台/加工機/販売所/防壁のレイアウト
- ジョイスティックの位置と大きさ
- 移動速度、採取1回の時間、投入1個の間隔
- カメラの追従速度と表示範囲
