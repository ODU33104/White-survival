# Stage 3 reference — clearing / shelter

Primary references:
- CreativeScope WS-S02
- CreativeScope WS-S07

## Loop

visible obstruction/snow -> immediate clearing -> resource gathering -> house/palisade construction -> survivors move into safety -> settlement visibly grows.

## Visual requirements

- Before/after state must fit on screen.
- Clearing cannot feel like attacking an invisible HP bar; snow/obstacle must visibly disappear.
- Building construction should happen in visible phases (foundation -> frame -> walls/roof).
- Survivors should physically relocate after shelter is finished.
- New structures should unlock another nearby action, keeping the player moving through the map.
