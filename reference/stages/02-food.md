# Stage 2 reference — fishing / food line

Primary references:
- CreativeScope WS-S01
- CreativeScope WS-S06
- Japanese March 2025 ad archive: https://note.com/koukoku_miruyo/n/na120d9d1aabf

## Loop

wood/fuel setup -> ice fishing or net fishing -> visible fish stack -> processing/cooking -> feed waiting survivors -> hire/automate workers.

## Visual requirements

- Ice hole or fishing equipment must be visually obvious without UI explanation.
- Fish should appear as large discrete carried items, not just a numeric counter.
- Processing stations should visibly transform raw fish into cooked food.
- Waiting survivors must be visible near the serving point so the purpose of the loop is obvious.
- Worker automation should physically move resources through the same path the player learned manually.
