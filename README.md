# Frostline Frontier

雪原サバイバル系のモバイル広告で見られる「短く、触っていて気持ちいいゲームループ」を、オリジナルのブラウザゲームとして組み直すプロジェクトです。

> リポジトリ名は `White-survival` ですが、ゲーム内では既存作品の名称・ロゴ・キャラクター・画像・音源を使用しません。

## 現在の実装

- PC: WASD / 矢印キー
- スマホ: 画面下半分をドラッグする仮想スティック
- 接近による自動採取・自動加工・自動戦闘
- 資源を背負って運ぶスタック表現
- 施設への高速投入、パーティクル、フローティング数値
- `localStorage` による進行状況・強化・所持コインの保存
- 永続アップグレード: 移動速度 / 運搬容量 / 採取力 / 戦闘力
- 全6ステージ

### ステージ

1. **火を絶やすな** — 伐採 → 運搬 → 暖炉
2. **氷上の食卓** — 釣り → 調理 → 給食
3. **雪を越えて** — 除雪 → 伐採 → 建築
4. **凍土の工場** — 原料 → 加工 → 組立 → 販売
5. **白夜の襲撃** — 資源回収 → 壁・武器強化 → 防衛戦
6. **最後の集落** — 採取・加工・建築・戦闘を組み合わせた総合ステージ

## 起動

静的サイトなので、`index.html` をHTTPサーバーから配信すれば動作します。

例:

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。

## 方針

広告のゲームプレイ感を研究しつつ、公開可能な独立作品にするため、ビジュアル・名称・素材はオリジナルで制作します。今後は操作感、アニメーション、音、ステージ固有ギミック、難易度調整を重点的に改善します。
